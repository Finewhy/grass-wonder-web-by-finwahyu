# Grass Wonder Fan Website 🍀

Website pengenalan karakter **Grass Wonder** dari *Uma Musume: Pretty Derby*. 

## Fitur Utama
- **Karusel Kostum Interaktif**: Menampilkan 4 variasi kostum Grass Wonder.
- **Informasi Lengkap**: Biografi, rekor balap asli (IRL), dan hubungan karakter.
- **Desain Modern**: Tema gelap elegan yang disesuaikan dengan warna seragam Grass Wonder.

## Teknologi
- HTML5
- CSS3
- JavaScript
